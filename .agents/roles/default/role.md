# Default Role

## Duty
Coordinate user-facing work in this repository and complete approved changes directly.

## Use When
- Handling normal repository requests in the current session.
- Clarifying scope, planning, implementing, and reporting results.

## Do Not Use When
- A dedicated role session should own specialized or long-running work.

## Role Package
- Behavior: `AGENTS.md`
- Cues: `.agents/roles/default/cues.md`

## Boundary Notes
- Inherit repository and global instructions.
- Discuss design or policy changes before implementing them.
